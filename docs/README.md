# รายงานผลการปฏิบัติงาน PA ปีงบประมาณ 2569 — นายภัทรพงษ์ มาตณาคุณ

เว็บไซต์นำเสนอรายงานผลการปฏิบัติงานตามข้อตกลงในการพัฒนางาน (Performance Agreement : PA)
ครูเคมี กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี โรงเรียนโคกคอนวิทยาคม สพม.หนองคาย

## โครงสร้าง
- `index.html` — หน้าเดียว 9 บท (ผู้รายงาน · ตารางธาตุ PA 15 ลักษณะงาน · ประเด็นท้าทาย · ตัวชี้วัด 8+4 · ผลงาน · กิจกรรม · จรรยาบรรณ · การพัฒนาตนเอง · นโยบาย สพฐ.)
- `css/style.css` — ธีม Obsidian / Indigo / Royal Purple / Champagne Gold, ฟอนต์ Trirong + Bai Jamjuree
- `js/scene.js` — อะตอม 3 มิติ (Three.js) ตอบสนองเมาส์
- `js/main.js` — เคอร์เซอร์อิเล็กตรอน, ปุ่มแม่เหล็ก, ตารางธาตุ, แกลเลอรี, ไลต์บ็อกซ์, เพลงบรรยากาศ (Web Audio)
- `js/data.js` — เนื้อหาจากรายงาน
- `assets/img` — รูป 193 ภาพ (+ thumbnails), `assets/*.pdf` — รายงานฉบับเต็มและประเด็นท้าทาย

## เปิดใช้งาน
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น `python -m http.server 8123` แล้วเข้า http://localhost:8123
รองรับ GitHub Pages ได้ทันที (มี `.nojekyll`)
