# รายงานผลการปฏิบัติงาน PA ปีงบประมาณ 2569 — นายภัทรพงษ์ มาตณาคุณ

ครูเคมี กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี โรงเรียนโคกคอนวิทยาคม สพม.หนองคาย

## เว็บไซต์
เปิดดูออนไลน์: **https://panissta23210-maker.github.io/phattharaphong-pa/**
โค้ดเว็บอยู่ในโฟลเดอร์ [`docs/`](docs/) (GitHub Pages ใช้โฟลเดอร์นี้เป็นต้นทาง)

## เอกสารในคลังนี้
| ไฟล์ | รายละเอียด |
|---|---|
| `รายงานผลการปฏิบัติงาน PA ... (ฉบับพิมพ์ 50 หน้า).docx / .pdf` | รายงานฉบับสมบูรณ์สำหรับส่งกรรมการ |
| `ประเด็นท้าทาย PA 2569 (1 หน้า) ... .docx / .pdf` | ข้อตกลงประเด็นท้าทาย 1 หน้า A4 |
| `รายงานผลการปฏิบัติงาน PA ... .docx` | ฉบับเต็ม 136 หน้า (ก่อนย่อ) |
| `โอมๆ ... รอบ 2.docx / .pdf` | แบบรายงานขอเลื่อนเงินเดือน รอบ 2 (ต้นฉบับเดิม) |
| `เกียติบัติ/` | เกียรติบัตร O-NET, คุรุสภา, สพฐ. |
| `*.JPG / *.HEIC` | ภาพกิจกรรมต้นฉบับจากกล้อง |

## เปิดเว็บในเครื่อง
```
python -m http.server 8123 --directory docs
```
แล้วเข้า http://localhost:8123
